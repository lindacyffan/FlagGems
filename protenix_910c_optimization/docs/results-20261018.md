# Ascend 910C Protenix 优化结果

## 优化技术

### 自研端到端优化

- TriangleAttention PSE 融合：用 `npu_fusion_attention` 替代原生 QK、加 bias、softmax、PV 的多算子分解路径，并按 Protenix 语义设置 `scale=1.0`，避免 float-mask SDPA 在 NPU 上落入低效 fallback。实现：`src/pse_patch_v1.py`。
- PSE 与 mask 语义拆分：区分 row mask 和 pair bias，将 `0/-1e9` 形式的 mask 转换为 NPU 可用的布尔 mask；不能安全转换时回退原实现，避免为了融合改变数值语义。实现：`src/pse_patch_v1.py`。
- 内存布局优化：尽量复用 broadcast PSE，避免物化真实 workload 下约 11GB 的 `[B,H,S,S]` 全量 bias 中间 tensor，同时保留可控的 expand/copy 模式用于正确性排查。实现：`src/pse_patch_v1.py` 与 `src/apb_pse_patch_v2.py`。
- Atom-pair Bias 路径统一：patch `primitives._attention`，同时覆盖 4D APB attention 和 3D local/AtomTransformer chunk attention；4D 归一化到 BNSD 布局，3D chunk 插入单 head 维后走同一个 fused kernel。实现：`src/apb_pse_patch_v2.py`。
- TriangleMultiplicativeUpdate 投影融合：将共享 `layer_norm_in(z)` 输入的 `a_g/a_p/b_g/b_p/g` 五组权重惰性拼接为一次矩阵乘，再按通道切分，减少五次独立 GEMM 和调度开销。实现：`src/tm_npu_patch.py`。
- 数值路径保护：TM 融合只改变投影组织方式，不改变数学计算；`inplace_safe` 和 cuequivariance 路径回退原实现，BF16 BMM 默认关闭，端到端对比保持 FP32 存储并关闭 TF32/AMP。实现：`src/tm_npu_patch.py`、`src/flagos_910c_launcher.py` 与 `benchmarks/run_same_config_pse.sh`。
- 运行时与可复现控制：统一 launcher 在导入模型前安装 NPU patch，固定输入、seed、单卡设备、cycle/steps、FP32、TF32/AMP/cache 开关以及 benchmark 环境变量，保证 H100 与 910C 结果同口径。实现：`src/flagos_910c_launcher.py` 与 `benchmarks/run_same_config_pse.sh`。

### TriAttention 专项优化

- 编译适配：用指针寻址替代 zero-stride block pointer，使 Triton TriangleAttention 能在 Ascend 910C 上编译运行。实现：`src/triatt_npu_patch.py`。
- 地址修正：修复 `N>1` 时 Q/K/V 基地址缺少 head 维偏移的问题，避免读到错误数据。实现：`src/triatt_npu_patch.py`。
- 数值路径：将 bias 作为 FP32 dot accumulator 传入 QK 矩阵计算，修复 QK 后置加 bias 的数值偏差。实现：`src/triatt_npu_patch.py`。
- 边界处理：显式处理 row/tail mask、Q/K/V/O 布局和输出地址。实现：`src/triatt_npu_patch.py`。
- 验证状态：单算子和局部验证有效；真实 replay 精度未达标，未计入最终端到端结果。

## 优化效果

相同 workload：`7WUX`、seed `101`、`N_msa=1302`、`N_token=1170`、cycle `10`、200 diffusion steps、FP32 存储、TF32 关闭、cache 关闭。

| 路线 | Forward | 实测相对 H100 速度 |
|---|---:|---:|
| H100 native FP32 | 116.53 s | 100% |
| Ascend 910C + PSE | 204.43 s | 57% |

910C+PSE 的端到端 forward 实测速度达到 H100 的 `57%`。精度方面，pLDDT、pTM、ipTM 和 ranking score 相对 H100 的差异均小于 `0.3%`，满足不超过 `5%` 的精度目标。
